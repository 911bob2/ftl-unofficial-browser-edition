# Desktop parity inventory

Target: the owner's unmodified Windows FTL 1.6.14 executable and official DAT, including Advanced Edition. This is an implementation in progress. Successful builds and simulated campaigns do not establish 1:1 parity.

The maintained sources are authoritative. The direct-fork baseline retained every transformed gameplay source before the duplicate upstream checkout and source-rewriting scripts were removed. Resources, third-party dependencies and notices remain in the maintained tree. Private assets and reverse-engineering output are excluded from Git and application images.

## Evidence and status

- The table below is the curated implementation matrix. Detailed content entries remain **implemented but unverified** until their specific behavior has been checked. **Verified** means the named regression passed; it does not certify every related interaction or animation.
- Executable addresses, hash, interpretation and corresponding tests are recorded in [original behavior notes](../ORIGINAL_BEHAVIOR.md). Decompiled output remains private.
- [All-UI presentation audit](../UI_PARITY.md) expands the hangar plan to every
  game screen. The button-branch review corrects state colors/font coordinates,
  crew/empty-card alignment and autofire presentation. New rendered-pixel/input
  checks cover these slices; complete native visual/audio acceptance remains open.

Every in-scope gap remains required implementation work. This inventory does not authorize deferring omissions or declaring a parity release while failures remain.
