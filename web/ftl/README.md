# FTL website assets

Public website artwork exported from https://subsetgames.com/ftl.html on
2026-10-16, © Subset Games:

- `logo.png`: https://subsetgames.com/img/ftllogo.png
- `space.png`: https://subsetgames.com/img/ftl/FTL_star_background1_flip.png
- `honeycomb.png`: https://subsetgames.com/img/backgrounds/bg_center.png

These are public website graphics, not exports from anyone's `ftl.dat`. They are
used with attribution in this unofficial fan project; if you represent Subset Games
and want them (or the project) removed, email ftl@911bob.dev.
`panel-frame.svg` is an original CSS border frame for this browser fork.

Chakra Petch Latin regular/semibold WOFF2 files come from the pinned
`@fontsource/chakra-petch` 5.3.0 package. Their SIL Open Font License is included
at `third_party/notices/ChakraPetch-LICENSE.txt`. The reference website's FTL
font URLs rejected binary downloads; those proprietary font files are not included.

All assets load from the application's own origin. No CDN, reference-site
request, video embed, tracking script or remote font is needed at runtime.
